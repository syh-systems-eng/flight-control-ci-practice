# Flight Control CI Practice

This project demonstrates a simple flight control application developed to practise modern Continuous Integration (CI) workflows using GitHub Actions.

## Objectives

- Practise Git branching workflows
- Implement automated unit testing with pytest
- Configure Continuous Integration using GitHub Actions
- Simulate regression detection through automated testing
- Build a portfolio project demonstrating software verification principles

## Technologies

- Python
- pytest
- Git
- GitHub
- GitHub Actions
